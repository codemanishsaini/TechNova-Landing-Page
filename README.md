# TechNova - Responsive Corporate Landing Page

## 📌 Project Overview

TechNova is a modern and fully responsive corporate landing page
developed as part of my Web Designing Internship.

The website is designed for a fictional software company that provides
smart software solutions for modern businesses.

## 🚀 Features

- Responsive Navigation Bar
- Hero Banner
- About Us Section
- Services Section
- Feature Cards
- Pricing Plans
- Testimonials Section
- Newsletter Subscription
- Contact CTA Section
- Professional Footer
- Responsive design for mobile, tablet and desktop
- CSS Flexbox and CSS Grid
- Hover effects and CSS transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- CSS Transitions
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work across:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

Media queries are used to adjust the layout and content for different
screen sizes.
